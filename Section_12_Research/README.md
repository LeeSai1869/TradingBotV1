# Research

Offline studies, reproducible report sources and research dashboards live here.
The chart and live runner remain in Sections 1–11.

- `cli/`: study, export and analysis commands.
- `reports/`: research results, configurations and reproducibility scripts.
- `ui/`: strategy analyzer browser assets.
- `fixes/`: archived research fixes and notes.
- `docs/`: research methods and study documentation.
- `launchers/`: optional research dashboard launcher.

From the repository root:

```sh
python3 -m Section_12_Research.cli.open_strategy_study --help
python3 -m Section_12_Research.cli.study_btc_hour_sequences --help
```

Runtime features that the app's research views consume remain in their owning
runtime sections. Moving files does not retire those features or replay history.
